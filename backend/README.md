# Career OS v2 Backend — Personal Engineering CMS REST API

Django 5 + Django REST Framework platform backend for Career OS v2.

## Technology Stack
- **Framework:** Django 5 & Django REST Framework
- **Auth:** SimpleJWT (JSON Web Tokens)
- **Database:** PostgreSQL (with SQLite fallback)
- **API Docs:** OpenAPI 3.0 / Swagger UI via `drf-spectacular`
- **Tooling:** `uv` (dependency management) & `ruff` (linting & formatting)
