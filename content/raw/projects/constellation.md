Constellation is a self-hosted cloud infrastructure platform designed for hands-on experimentation with distributed network routing, container orchestration, and homelab security.

### Infrastructure & DevOps Stack

- **Traefik Reverse Proxy & TLS**: Automated SSL certificate generation (Let's Encrypt) and dynamic routing across internal microservice endpoints.

- **Tailscale Mesh VPN**: Zero-trust, secure overlay network connecting remote devices and local homelab nodes.

- **System Monitoring & Metrics**: Prometheus and Grafana dashboards tracking CPU/RAM metrics, network throughput, and container health checks.

- **Automated Deployments**: Infrastructure-as-code automation scripts managing container lifecycle, volume backups, and system upgrades.
