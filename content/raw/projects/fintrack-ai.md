FinTrack AI is a robust personal finance backend platform designed to automate transaction categorization and deliver real-time financial insights.

### Core Backend Architecture

- **Django REST Framework API Layer**: High-throughput RESTful endpoints handling transaction ingestion, user authentication, and budget reporting.

- **PostgreSQL Database Engine**: Relational schema design with optimized indexing over financial ledgers, recurring payments, and analytics aggregates.

- **AI Expense Categorization**: Asynchronous background pipeline using machine learning and LLM heuristics to classify raw banking transactions into structured categories.

- **Containerized Deployment**: Fully containerized using Docker and Docker Compose for reproducible local development and cloud production deployment.
